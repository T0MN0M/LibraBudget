## Login System Documentation

The login screen will be the first page that users see when accessing the web application for the first time
<br>

## Login Features

The login screen has six different interactions:

1. A form to enter a username
2. A second form to enter a password
3. A forgot password prompt that the user can click on to change their password
4. A login button to verify the inputted username and password which will lead to the application’s main dashboard
5. A register button for new or first-time users
6. A home button to access the application’s main landing page/hero page
